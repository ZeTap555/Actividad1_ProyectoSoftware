# Actividad 1 - Proyecto de Software



## 📝 Descripción
Este proyecto corresponde al enunciado 2 de la actividad 1. La misma consistió en construir un sitio web estático responsivo (estrictamente HTML y CSS, sin JavaScript) para el catálogo de cursos de un instituto de idiomas, utilizando exactamente el mismo *prompt*.


## 📂 Estructura del Repositorio
El código está dividido en dos directorios principales para facilitar la comparación:

* 📁 **`version_ia_1/`**: Solución generada por **Gemini**. 

* 📁 **`version_ia_2/`**: Solución generada por **Claude**. 
  

Ambas carpetas contienen su respectivo archivo `index.html`, la hoja de estilos `estilosIA.css` y el directorio `/programas` con los PDFs de prueba para los enlaces de descarga.
